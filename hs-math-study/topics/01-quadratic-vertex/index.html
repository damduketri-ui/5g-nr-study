01 · completing the square

왜 굳이
완전제곱식으로
고쳐 쓰는가

y = x² − 6x + 5 를 보고는 최솟값을 알 수 없습니다. 그런데 y = (x − 3)² − 4 로 고쳐 쓰는 순간, 계산 없이 −4가 눈에 들어옵니다. 식은 그대로인데 무엇이 달라진 걸까요.

접시 하나로 끝까지 갑니다

이차함수의 그래프는 접시입니다. 이 자료에서는 끝까지 접시라고 부르겠습니다.

y = x² 은 원점에 놓인 접시입니다. 바닥이 (0, 0)에 있습니다. 그런데 우리가 실제로 만나는 식은 y = x² − 6x + 5 처럼 생겼고, 이 식만 봐서는 접시 바닥이 어디에 놓였는지 알 수 없습니다.

완전제곱식(perfect square form)은 접시 바닥의 주소입니다. 식을 바꾸는 게 아니라, 같은 식을 주소가 보이도록 다시 쓰는 것입니다.

  1. y = x² − 6x + 5 주어진 식. 바닥이 어딘지 안 보인다
  2. = (x² − 6x + 9 − 9) + 5 (−6 ÷ 2)² = 9 를 더하고 곧바로 뺀다 — 값은 그대로
  3. = (x² − 6x + 9) − 9 + 5 앞 세 항만 묶는다
  4. = (x − 3)² − 4 바닥이 (3, −4)에 있다

3은 −6의 절반이고, 9는 그 절반의 제곱입니다. (x − 3)² = x² − 6x + 9 이므로 9가 남아돌고, 그 9를 도로 빼 준 것이 −4의 정체입니다.

가로·세로 눈금 모두 한 칸 = 1 로 같은 배율입니다. 두 곡선은 모양이 완전히 같습니다 — 자리만 옮겼습니다.

두 곡선이 겹쳐 보이지 않는 이유는 단 하나, 놓인 자리가 다르기 때문입니다. x² 앞의 계수 1이 같으면 접시의 생김새는 언제나 같습니다. 그래서 이차함수를 파악한다는 건 결국 바닥이 어디인지를 찾는 일입니다.

최솟값이 −4인 이유는 한 줄입니다

y = (x − 3)² − 4 에서 (x − 3)² 부분을 봅시다. 어떤 실수를 제곱해도 음수가 되지 않습니다. 그러니까

  1. (x − 3)² ≥ 0 실수의 제곱은 0 이상 — 이게 전부다
  2. (x − 3)² − 4 ≥ 0 − 4 양변에서 4를 뺐다
  3. y ≥ −4 y는 −4보다 작아질 수 없다

그리고 등호는 (x − 3)² = 0 일 때, 즉 x = 3 일 때만 성립합니다. 그래서 "x = 3 에서 최솟값 −4"가 됩니다. 그래프를 그릴 필요도, 값을 여러 개 대입해 볼 필요도 없습니다.

실수 범위에서만 그렇습니다. "제곱은 0 이상"은 x가 실수일 때의 이야기입니다. 복소수까지 가면 i² = −1 이므로 성립하지 않습니다. 2022 개정 교육과정 「공통수학1」 방정식과 부등식

이제 문자로 — 절차는 똑같습니다

숫자로 한 번 해봤으니 문자는 그 절차에 이름을 붙인 것뿐입니다. 다만 a ≠ 0 이어야 합니다. a = 0 이면 x² 항이 사라져 애초에 이차함수가 아닙니다.

  1. y = ax² + bx + c a ≠ 0
  2. = a(x² + (b/a)x) + c x가 든 항에서 a를 묶어낸다
  3. = a(x² + (b/a)x + (b/2a)² − (b/2a)²) + c 계수의 절반의 제곱을 더하고 뺀다
  4. = a(x + b/2a)² − b²/4a + c a를 곱해 괄호 밖으로 꺼냈다
  5. = a(x + b/2a)² − (b² − 4ac)/4a c − b²/4a 를 한 분수로 합쳤다

즉 y = a(x − p)² + q 이고,

p = −b/2a접시 바닥의 x좌표 (대칭축)
q = −D/4a접시 바닥의 y좌표 (최댓값 또는 최솟값)

여기서 D = b² − 4ac 가 튀어나옵니다. 근의 공식에서 보던 그 판별식(discriminant)입니다. 판별식과 최솟값이 따로 배우는 남남 같지만, 사실 같은 계산의 앞뒷면이었습니다.

왜 하필 같은 D인가. 접시 바닥의 높이가 q = −D/4a 이므로, a > 0(위로 열린 접시)일 때 바닥이 x축 아래로 내려가려면 q < 0, 곧 D > 0 이어야 합니다. 바닥이 x축 아래에 있어야 곡선이 x축을 두 번 가로지릅니다. "D > 0 이면 서로 다른 두 실근"은 이 문장을 줄여 쓴 것입니다. 계수 a, b, c가 실수일 때

직접 움직여 보기

a, b, c를 바꾸면 접시의 모양과 자리가 어떻게 따라 움직이는지 보세요. 특히 D가 0을 지나는 순간과 a가 0이 되는 순간에 무엇이 무너지는지 확인해 보십시오.

가로·세로 눈금 모두 한 칸 = 1 로 같은 배율입니다. 판정 상자가 분홍으로 바뀌는 자리가 경계입니다 — D = 0(근이 하나로 붙는 순간), a = 0(이차함수가 아니게 되는 순간).

여기서 틀린다 — a의 부호를 확인하지 않는다. q = −D/4a 는 a > 0 이면 최솟값, a < 0 이면 최댓값입니다. "꼭짓점 = 최솟값"으로 외워 두면 a < 0 인 문제에서 통째로 틀립니다. 위에서 a를 음수로 내려 접시가 뒤집히는 것을 확인해 보세요.

정의역이 실수 전체일 때

y = ax² + bx + c (a ≠ 0, a·b·c는 실수) · 꼭짓점 (−b/2a, −D/4a), D = b² − 4ac
a의 부호접시 모양최댓값최솟값
a > 0위로 열림없다 (한없이 커진다)−D/4a (x = −b/2a)
a < 0아래로 열림−D/4a (x = −b/2a)없다 (한없이 작아진다)
a = 0접시가 아님 — 직선이차함수가 아니므로 이 표가 적용되지 않는다

"최댓값이 없다"는 아무리 큰 값도 넘어선다는 뜻입니다. 답을 못 찾은 게 아니라 존재하지 않는 것이므로, 답안에는 "최댓값은 없다"라고 써야 합니다.

범위가 정해져 있으면 이야기가 달라집니다

시험에서 실제로 물어보는 것은 대개 "0 ≤ x ≤ 2 에서의 최댓값과 최솟값"처럼 범위가 잘린 형태입니다. 그리고 여기가 가장 많이 틀리는 자리입니다.

이유는 간단합니다. 접시 바닥이 그 범위 안에 있다는 보장이 없기 때문입니다. 바닥이 범위 밖에 있으면 그 안에서는 곡선이 한쪽으로 계속 오르거나 내려가기만 하므로, 답은 양 끝점에서 나옵니다.

가로·세로 눈금 모두 한 칸 = 1 로 같은 배율입니다. 꼭짓점이 범위 밖이면 분홍으로 바뀝니다.

y = x² − 6x + 5 = (x − 3)² − 4 · 꼭짓점 (3, −4) · a = 1 > 0
x의 범위꼭짓점 x=3최댓값최솟값어디서 나오나
0 ≤ x ≤ 2범위 밖(오른쪽)5−3양 끝 x=0, x=2
2 ≤ x ≤ 6범위 안5−4최소는 꼭짓점 x=3
4 ≤ x ≤ 6범위 밖(왼쪽)5−3양 끝 x=4, x=6

첫 번째와 세 번째 범위의 값이 똑같은 것은 우연이 아닙니다. 0 ≤ x ≤ 2 와 4 ≤ x ≤ 6 은 대칭축 x = 3 을 사이에 두고 서로 거울상이라서 값이 같습니다. 대신 최댓값이 나오는 x는 0에서 6으로, 최솟값이 나오는 x는 2에서 4로 뒤바뀝니다.

여기서 틀린다 — 꼭짓점을 무조건 답으로 쓴다. 0 ≤ x ≤ 2 에서 최솟값을 −4라고 답하면 틀립니다. x = 3 은 이 범위 안에 없으므로 −4는 애초에 나올 수 없는 값입니다. 순서를 이렇게 고정하세요 — ① 완전제곱식으로 고쳐 꼭짓점을 구한다 → ② 꼭짓점이 범위 안인지 먼저 확인한다 → ③ 범위 안이면 꼭짓점과 양 끝을, 밖이면 양 끝만 비교한다.

남는 것

  • 완전제곱식은 접시 바닥의 주소다. y = a(x − p)² + q 로 고치면 꼭짓점 (p, q)가 그대로 읽힌다. 계산이 아니라 표기법의 문제다.
  • 최솟값이 q인 근거는 "제곱은 0 이상" 한 줄이다. 그리고 a > 0 이면 최솟값, a < 0 이면 최댓값이다. a의 부호를 먼저 본다.
  • 꼭짓점 y좌표 q = −D/4a. 판별식은 근의 개수를 세는 도구이기 이전에, 접시 바닥이 x축에서 얼마나 떨어져 있는지를 재는 자다.
범위가 잘려 있으면 꼭짓점이 그 안에 있는지부터 확인합니다. 밖이면 답은 양 끝점에서 나옵니다.
