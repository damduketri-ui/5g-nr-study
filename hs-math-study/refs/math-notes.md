## 01 이차함수의 최대·최소

### 쓴 정의·정리

| 항목 | 내용 | 성립 조건 | 확인 |
|---|---|---|---|
| 이차함수 | y = ax² + bx + c | **a ≠ 0** · a, b, c는 실수 | 교과서 공통 |
| 완전제곱식(표준형) | y = a(x − p)² + q | a ≠ 0 | 교과서 공통 |
| 꼭짓점 | (p, q) = (−b/2a, −D/4a) | a ≠ 0 | 유도 (아래) |
| 대칭축 | 직선 x = −b/2a | a ≠ 0 | 유도 |
| 판별식 | D = b² − 4ac | 계수가 **실수**일 때만 근의 개수를 판정한다 | 교과서 공통 |
| 최대·최소 | a > 0 → x = −b/2a 에서 최솟값 −D/4a, 최댓값 없음<br>a < 0 → 같은 x 에서 최댓값 −D/4a, 최솟값 없음 | 정의역이 실수 전체 | 유도 |
| 제곱의 부호 | 모든 실수 t 에 대해 t² ≥ 0, 등호는 t = 0 일 때만 | **실수 범위에서만** (복소수에서는 i² = −1) | 교과서 공통 |

### 유도 (계산 근거)

```
ax² + bx + c                                       (a ≠ 0)
= a(x² + (b/a)x) + c                               x가 든 항에서 a를 묶는다
= a(x² + (b/a)x + (b/2a)² − (b/2a)²) + c           절반의 제곱을 더하고 뺀다
= a(x + b/2a)² − a·b²/(4a²) + c
= a(x + b/2a)² − b²/(4a) + c
= a(x + b/2a)² + (4ac − b²)/(4a)
= a(x + b/2a)² − D/(4a),        D = b² − 4ac

⇒ p = −b/2a,  q = −D/4a
```

`a > 0` 일 때 q < 0 ⟺ D > 0 이고, 이것이 "D > 0 이면 서로 다른 두 실근"의 도형적 의미다.
(접시 바닥이 x축 아래에 있어야 곡선이 x축을 두 번 가로지른다.)
`a < 0` 일 때는 부등호가 뒤집혀 q > 0 ⟺ D > 0 이다.
→ `tools/verify-math.py` `check_01_discriminant()` 가 a·b·c 격자 2704가지를 전수 확인한다.

### 자료에 실은 값

```
y = x² − 6x + 5 = (x − 3)² − 4
  꼭짓점 (3, −4) · 대칭축 x = 3 · D = (−6)² − 4·1·5 = 16 · 근 x = 1, 5

제한된 범위 (a = 1 > 0, 꼭짓점 x = 3)
  0 ≤ x ≤ 2   꼭짓점 밖   최대 5 (x=0)   최소 −3 (x=2)
  2 ≤ x ≤ 6   꼭짓점 안   최대 5 (x=6)   최소 −4 (x=3)
  4 ≤ x ≤ 6   꼭짓점 밖   최대 5 (x=6)   최소 −3 (x=4)
  ※ [0,2]와 [4,6]은 대칭축 x=3에 대한 거울상이라 값이 같고 위치만 뒤바뀐다
```

→ `tools/verify-math.py` `check_01_restricted()` 가 공식을 쓰지 않고 구간을 40만 점 훑어
   위 값과 대조한다. 꼭짓점이 범위 밖인 구간에서 최대·최소가 항상 양 끝점에서 나오는지도 확인한다.

### 그림의 좌표 매핑

```
그림1  x∈[−3,7], y∈[−5.5,7]   X(x) = 140 + 30x   Y(y) = 240 − 30y
그림2  x∈[−9,9], y∈[−10,10]   X(x) = 240 + 22x   Y(y) = 250 − 22y   (곡선은 스크립트가 계산)
그림3  x∈[−1,8], y∈[−5.5,7]   X(x) =  76 + 30x   Y(y) = 240 − 30y
```

세 그림 모두 가로·세로 배율이 같다(각각 30, 22, 30 px/단위).
그림1·3에 손으로 박아 넣은 점의 좌표는 `check_01_pixels()` 가 위 식으로 되짚는다.

### 자료에서 짚은 오개념

| 오개념 | 실제 | 위치 |
|---|---|---|
| 꼭짓점 = 항상 최솟값 | a < 0 이면 최댓값이다 | 그림2 아래 `.note.trap` |
| 범위가 있어도 꼭짓점 값이 답 | 꼭짓점이 범위 밖이면 답은 양 끝점에서 나온다 | 그림3 아래 `.note.trap` |
| a = 0 도 이차함수 | a = 0 이면 직선이고 최대·최소가 없다 | 그림2 슬라이더에서 직접 확인 |
