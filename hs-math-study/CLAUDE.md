# 고1 수학 직관 — 작업 규칙

이 저장소는 고등학교 1학년 수학(2022 개정 교육과정 「공통수학1」·「공통수학2」)을
**직관적으로 이해하기 위한 학습 자료 모음**이다.
읽는 사람은 지금 그 개념을 모르는 학생이다. 교과서를 대체하는 것이 목표가 아니라,
교과서와 문제집을 읽을 수 있는 몸을 만드는 것이 목표다.

한 세션에 **개념 하나 = 챕터 하나 = HTML 한 장**을 추가한다. 여러 개를 한꺼번에 쓰지 않는다.

---

## 1. 사실 정확성 — 가장 중요한 규칙

수학은 "대체로 맞는 말"이 가장 위험한 영역이다. 조건 하나가 빠지면 그냥 거짓이 된다.
아래를 반드시 지킨다.

- **정리·공식에는 성립 조건을 반드시 함께 쓴다.** 조건 없는 공식은 쓰지 않는다.
  - `a ≠ 0` (이차식이라는 조건) · `분모 ≠ 0` · `근호 안 ≥ 0` · "실수 범위에서"
  - 예: "D > 0이면 서로 다른 두 실근" ← **계수가 실수일 때만** 성립한다
- **유도한 식은 계산 과정을 남긴다.** HTML에는 주석으로, 마크다운에는 본문에.
  ```
  <!-- ax²+bx+c = a(x + b/2a)² + c − b²/4a
       q = c − b²/4a = (4ac − b²)/4a = −D/(4a),  D = b²−4ac -->
  ```
- **역이 성립하는지 따로 확인한다.** "A이면 B"를 썼으면 "B이면 A"가 참인지 검토하고,
  참이 아니면 반례를 자료 안에 넣는다. 이 저장소에서 가장 자주 나는 사고다.
- **확신이 낮은 것은 반드시 표시한다.** HTML은 `<!-- VERIFY: 근거 필요 -->`,
  마크다운은 `⚠️ 미검증`. 표시 없이 넘어가는 것이 가장 나쁜 실패다.
  특히 **교육과정 성취기준 코드와 학년·과목 배치**는 확인 전까지 반드시 미검증으로 둔다.
- **추측으로 숫자를 채우지 않는다.** 모르면 "확인 필요"라고 쓴다.
- 확인한 항목은 `refs/math-notes.md`에 옮겨 적고 확인일을 남긴다.
- 계산 결과를 실었으면 **`python3 tools/verify-math.py`를 돌려 통과시킨 뒤 커밋**한다.
  새 챕터의 수치·주장이 생기면 이 스크립트에 검산 항목을 추가한다. 스크립트는
  표준 라이브러리만 쓴다(설치 없이 돌아가야 한다).

근거로 삼는 것: 2022 개정 교육과정 수학과 교육과정(교육부 고시) · 검정 교과서 공통 서술.
교육과정 원문: https://ncic.re.kr (국가교육과정정보센터, 무료)

## 2. 설명 방식

- **구체적인 수 → 그림 → 일반화된 기호** 순서로 간다. 문자부터 시작하지 않는다.
  `x² − 6x + 5`를 먼저 손으로 고쳐 보이고, 그다음 `ax² + bx + c`로 올라간다.
- 비유는 하나만 쓰고 끝까지 밀고 간다. 비유를 계속 갈아타면 오히려 헷갈린다.
- **학생이 실제로 틀리는 지점을 챕터마다 최소 하나 짚는다.** `.note.trap`으로 표시한다.
  "이걸 왜 배우나"보다 "여기서 왜 틀리나"가 훨씬 오래 남는다.
- 표로 정리 가능한 것은 표로. 문단으로 늘어놓지 않는다.
- 용어는 **한글 + 영문 병기**를 첫 등장 시 한 번. 이후 한글만.
  예: "판별식(discriminant, D)" → 이후 "판별식" 또는 "D"
- 각 자료 끝에는 "그래서 뭐가 남는가"를 3줄 이내로 정리한다.

## 3. 시각 자료

- **인라인 SVG로 직접 그린다.** 이미지 파일이나 외부 수식·그래프 라이브러리를 쓰지 않는다.
  텍스트라서 diff가 읽히고, 값이 바뀌면 그 자리에서 고칠 수 있다.
- **좌표축은 실제 비율로 그린다.** x축 1칸과 y축 1칸의 길이가 다르면 캡션에 명시한다.
  ("세로는 가독성을 위해 2배로 늘렸습니다")
- 그래프의 점·선은 **식에서 계산해서 찍는다.** 눈대중으로 그리지 않는다.
  꼭짓점·근·절편의 좌표는 SVG 주석에 계산식을 남긴다.
- 인터랙션은 **개념을 검증할 수 있을 때만** 넣는다. 슬라이더를 움직였을 때
  학생이 "아, 여기서 바뀌는구나"를 발견할 수 있어야 한다. 장식용 애니메이션은 뺀다.
  경계(D = 0, a = 0, 분모 = 0 같은 자리)를 반드시 지나가게 범위를 잡는다.
- 수식은 `.math` / `.eq` 클래스로 쓴다. 유도는 `.eq ol`에 한 줄씩,
  각 줄 오른쪽에 `<span class="why">`로 "무엇을 했는지"를 적는다.
- 모든 SVG에 `<title>`과 `<desc>`를 넣는다.

## 4. 스타일

`assets/base.css` 밖에서 **새로운 색을 정의하지 않는다.** 토큰만 쓴다.

| 토큰 | 의미 | 이 색이 나오면 학생은 이렇게 읽는다 |
|---|---|---|
| `--given` / `--given-bg` | 주어진 것, 정의, 가정 | 문제가 준 것 |
| `--result` / `--result-bg` | 결과, 성립, 구한 답 | 여기가 목적지 |
| `--aux` / `--aux-bg` | 보조선, 소거되는 항, 중간 과정 | 답이 아니라 도구 |
| `--break` / `--break-bg` | 반례, 틀리는 지점, 경계 | 여기서 무너진다 |

색의 의미는 자료 전체에서 동일해야 한다. 한 자료에서 파랑이 "주어진 것"이었다면
다른 자료에서 파랑을 "정답"으로 쓰지 않는다.

- **`text-transform: uppercase`를 쓰지 않는다.** 수학에서 대문자와 소문자는 서로 다른 기호다.
  (`b² − 4ac` ≠ `B² − 4AC`, 집합 `A`와 원소 `a`) 영문만 들어가는 eyebrow만 예외다.
- 서체: 제목 `Gothic A1` 900 / 본문 `IBM Plex Sans KR` 300 / 수식·수치 `IBM Plex Mono`
- 새 자료는 `_template/index.html`을 복사해서 시작한다.

## 5. 새 자료를 추가할 때

1. `_template/index.html`을 `topics/NN-슬러그/index.html`로 복사
2. 상단 `<title>`, eyebrow 번호, 이전/다음 링크 수정
3. **`index.html`(루트) 목차에 항목 추가** — 빠뜨리면 자료가 고아가 된다
4. 앞 챕터의 pager "다음" 링크를 새 챕터로 연결
5. 근거로 삼은 정의·정리를 `refs/math-notes.md`에 누적
6. `tools/verify-math.py`에 이번 챕터 검산 함수를 추가하고 통과시킨다
7. 커밋 메시지는 `add: 01 이차함수의 최대·최소` / `fix: 01 판별식 부호 오기 수정` 형식

## 6. 품질 기준

새 자료를 내보내기 전 확인:

- [ ] `python3 tools/verify-math.py`가 통과하는가
- [ ] 모든 공식에 성립 조건이 적혀 있는가 (`a ≠ 0`, 실수 범위 등)
- [ ] "역도 성립하는가"를 검토했는가 · 아니라면 반례를 넣었는가
- [ ] 학생이 틀리는 지점(`.note.trap`)이 하나 이상 있는가
- [ ] `VERIFY` 표시가 남아 있다면 의도한 것인가
- [ ] 그래프의 좌표가 식에서 계산된 값인가 (눈대중이 아닌가)
- [ ] 휴대폰 폭(360px)에서 읽히는가 (넓은 SVG는 `.stage--scroll`로 감쌌는가)
- [ ] 키보드 Tab으로 인터랙션에 접근되는가, 포커스 링이 보이는가
- [ ] SVG에 `<title>`/`<desc>`가 있는가
- [ ] 루트 `index.html`에 링크했고, 앞 챕터의 pager를 이었는가
